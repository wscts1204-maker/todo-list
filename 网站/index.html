它是怎么跑起来的

一句话：没有账号、没有服务器、没有网络请求。

一个文件就是全部

整个应用是一个 index.html，不引用任何 CDN 资源。双击本地文件即可使用，断网也能正常读写。

数据只在本机

任务、清单、回收站存 localStorage，附件本体存 IndexedDB。换浏览器、换设备或清除浏览器数据都会丢失，长期保存靠导出备份。

首次打开有 27 条

第一次打开会自动导入一份内置首批清单并按文本去重，之后靠版本号判断不再重复执行。

本站由链接抽取 + 源码逐条核对生成（本机无 Python 运行库与 defuddle，采用 curl 抓线上原文 + Node 解析 DOM 骨架与常量的降级路径）。功能与数字以线上 index.html 和仓库 README.md 为准。本站不联网、不写入任务数据，主题选择只记在浏览器里。
