# 我的待办清单

一个单文件的待办事项网页：打开即用，不需要安装、不需要联网、不需要构建。

## 用法

- 直接下载 `index.html` 双击用浏览器打开；或
- 访问 GitHub Pages 部署后的在线地址（见下方「开启 GitHub Pages」）

## 说明站

仓库里另有一份讲这个页面的说明小站，同样零依赖、零 CDN、双击 `site/index.html` 即开（在线：`https://<你的用户名>.github.io/<仓库名>/site/`）：

- **总览**（`site/index.html`）：一页看清它有哪些能力，页面上的数字（模块数、功能条数、常量数、泳道数、方块数、连线数）是运行时从 `site/assets/data.js` 的数组长度算出来的，不是手写死的。
- **功能清单**（`site/features.html`）：按页面区块归纳成 8 个模块共 47 条能力，左侧目录可跳转并随滚动高亮，顶部搜索框按关键词逐条过滤。
- **业务流程图**（`site/flow.html`）：7 条泳道、45 个方块、56 条连线（其中 21 条带标签）的完整流程图，可缩放、可点选方块高亮相关连线、可打印。
- **数据与架构**（`site/data.html`）：6 条存储与边界说明 + 17 行关键常量，每行第三列给的是源码里的依据。

全站支持浅色/深色，主题偏好存在 `localStorage` 的 `flowdoc.theme`，和待办页自己的 `todo.*` 键互不影响。描述一律以线上 `index.html` 源码为准，不含推测。

说明站的动效与线上页面共用同一套纪律（`site/assets/tokens.css` 里的 `--ease-enter` / `--dur-enter` / `--dur-hover` / `--dur-panel` 四个变量，取值与 `index.html` 逐字相同）：首屏 `fade-up` 进场，其余板块由 `site.js` 给 `.shell` 的直属子块补上 `.reveal` 后用同一个 `IntersectionObserver` 参数（`threshold: .12`、`rootMargin: '0px 0px -40px 0px'`）播一次揭示——四页的板块容器并不统一（总览与数据页是 `section`、功能清单是 `.split`、流程图是 `.stage`），所以由脚本统一打标，不在四个 HTML 里各写一遍，`.pager` 与页脚跳过。藏起来同样只认 JS 自己加的 `html.reveal-on`，脚本没跑到就是全部可见。业务流程图页另有一条 `dash-march` 走线动画，只加在本来就是点线的旁路边上（`stroke-dasharray: 5 4`，偏移量 `-18` 是这个周期的整数倍，循环接缝看不出来），实线一律不动——这张图里虚线和点线是有含义的（蓝虚线＝写存储，灰点线＝旁路），选中时把实线改成虚线会和图例打架，所以选中只加粗。减弱动效与打印下这些全部关掉（实测：`prefers-reduced-motion: reduce` 下进场时长压到 `1e-05s`、`scroll-behavior` 变 `auto`、揭示内容 `opacity: 1`；切 `print` 后 `path.dash` 的 `animation-name` 变 `none`）。

## 功能

- 添加任务，回车或点击「➕ 添加任务」
- 多清单分开：清单以标签页的形式排在输入框上方（每个标签带一个「还剩几件待办」的小角标），点一下就整页换成那个清单的任务。点「＋ 新建清单」新建（最多 12 个、名字最多 12 个字），点右侧的「⋯」可以重命名或删除当前清单——删除时里面的任务会先进回收站（30 天内还能恢复），其他清单不受影响，且至少会留一个清单。默认那个清单沿用老键名，所以升级前存下的任务会原样出现在「我的清单」里，不需要迁移。快速添加、筛选、统计、日历、回收站都只看当前清单，切来切去互不干扰
- 任务跨清单搬运：展开任意一条任务的详情，下面有一行「移到其他清单…」的下拉，选中就搬过去——备注、子任务、附件、置顶、重复、提醒都一起带走，6 秒内可撤销；批量管理里选中多项后，工具条上同一颗下拉可以一次搬好几条。只有一份清单时这两处都不会出现（批量那颗会置灰）
- 清单排序：输入框上方那排清单标签可以直接按住往左右拖，拖动时会在该落下的位置显示一条竖线，松手即生效；手机上同样能拖。位移不到 6 个像素仍算「点开这个清单」，不会误改顺序
- 批量粘贴建任务：在输入框里直接粘贴一段多行文字（用换行、`、`、`，`、`,`、`；`、`;` 分隔都行），会自动弹出「批量添加」面板；也可以点输入框下方的「⧉ 批量粘贴」手动展开。每一行变成一条待确认的任务，面板里能逐行看到结果、点 × 删掉不要的，行内照样认 `#分类`、`!高`、`@周五`、`~每周` 这套快速添加语法；没写属性的行会沿用上方当前选好的优先级、到期日、分类、重复。一次最多 50 条，超出的会截断并提示。点「添加这 N 条」一次性入库（支持 6 秒撤销），`Ctrl+Enter` 等同于点添加，`Esc` 收起
- 任务附件：展开任务详情，最下方是「附件」区，点「 添加附件」选文件（可多选）就能挂到这条任务上。每条任务最多 8 个附件、单个最大 5 MB，行上会显示文件名、大小和「下载」「删除」两个按钮，收起详情后任务行上留一个回形针标记。附件本体存在浏览器本地的 IndexedDB（`todo-files`）里，不上传到任何服务器，任务数据本身只记一条文件名/大小的元数据；删掉附件或删掉任务后，对应的文件会在页面空闲时自动回收，回收站里还留着的任务其附件不会被回收。图片附件还会另存一张最长边 160px 的 webp 缩略图（同一个 `todo-files` 库里的 `thumbs` 仓库）：展开详情时图片排成缩略图网格，收起后任务行上最多挂两枚 26px 小图、多出的收成「+N」；点任意一张打开大图查看器，多图时可点按钮或用 `←` `→` / `PageUp` / `PageDown` 翻页、`Esc` 关闭，查看期间新增或删除附件会实时跟上，图片全删光时自动关闭。缩略图是派生数据，不进备份。要带到别的设备上，用页面底部的「⬇ 导出备份」，附件会一起打包进 JSON（见「数据存储」）
- 打卡热力图与本周小结：「数据统计」卡片底部新增两块。「本周小结」用四个格子给出本周完成数、比上周多/少几个、这周有几天打了卡、最活跃是星期几，下面一句话带上连续打卡天数。「打卡热力图」是近 20 周、周一开头的方格图（一格一天，颜色越深当天完成得越多，还没到的日子留空，今天带一圈描边），鼠标悬停能看到「10月8日：完成 2 个」。两块都按任务的完成时间统计，一条完成记录都没有时自动隐藏，不影响折叠
- 一句话快速添加：在输入框里一行写完，用符号带出属性——`#分类`、`!高`/`!中`/`!低`（`!高优先` 这种写法也认）、`@今天`/`@明天`/`@后天`/`@大后天`/`@周五`/`@下周三`/`@10-20`/`@2026-10-20`、`~每天`/`~每周`/`~每两周`/`~每月`。不带符号的自然说法（「明天」「每周一」「10-20」）也认，全角符号（`＃！＠～`）同样有效。输入时会有一行提示实时显示识别结果，认不出来的部分照原样当任务名。示例：`写周报 #工作 !高 @周五 ~每周`
- 优先级：高 / 中 / 低，用不同颜色标识，添加前在「优先级」处选择；快速添加里的 `!高` 会覆盖这里的默认选择
- 到期日：添加时可选填「到期日」（也可在编辑时改），列表上显示「逾期 N 天 / 今天到期 / N 天后到期 / 10/14 到期」，逾期为红色
- 重复任务：给任务设置「每天 / 每周 / 每月」，勾选完成后会自动排出一条下一次的任务（到期日顺延；已经逾期的从今天往后推，不背旧账；每月按当月末日夹紧；没填到期日的重复任务照样重新排出一条）。完成的那条仍保留在历史里参与统计，列表上重复任务带循环图标标记
- 按日期筛选：全部 / 已逾期 / 今天到期 / 未来 7 天 / 无日期，筛选结果计数显示在按钮上，选择会被记住
- 分类 / 标签：给任务打分类，最多 4 个（输入框会联想已有分类、输入新名字即新建，空格 / 逗号 / 顿号分隔可一次填多个）；列表上方「按分类筛选」可切换，计数与日期筛选叠加生效；快速添加里连写 `#工作 #学习` 可一次打两个分类；自带的首批清单已按 自媒体 / AI工具 / 项目开发 / 考证备考 / 理财赚钱 / 健康形象 / 生活杂事 分好类
- 分类管理：「按分类筛选」那一行最右边多了一颗虚线框的「管理分类」，点开是一个面板，把用过的分类按字母顺序列出来，每条写着「N 项待完成 · M 项已完成」，右侧三颗操作：「改名」（行内变成输入框，回车或点「保存」；改成已经存在的名字就等于合并这两个分类）、「合并到…」下拉（只有一个分类时禁用）、「去掉标记」（从所有任务上摘掉这个分类，任务本身一条都不删）。这些改动在**所有清单**里一并生效，回收站里躺着的那些年同名分类也跟着改；改完 6 秒内可撤销。面板上的数量只数各清单的任务，不含回收站
- 分类配色：每个分类有一个稳定色相，七个内置分类是写死的对应关系（自媒体=紫、AI 工具=靛蓝、项目开发=天蓝、考证备考=琥珀、理财赚钱=绿、健康形象=玫红、生活杂事=石板灰），新出现的分类按名字哈希从八档里挑一档，所以同一个分类在哪份清单、哪台设备、哪个浏览器上都是同一个颜色。颜色出现在五个地方：任务行上的分类胶囊、展开详情里那排可删的胶囊、「按分类筛选」每个按钮前面的小圆点、「数据统计 · 按分类完成率」每行前面的小圆点，以及「管理分类」面板里分类名前那个标签图标。不喜欢自动分配的那一档，在「管理分类」面板里点这一行的「换色」（按钮上带当前色的小圆点，悬停提示写着「当前色 X，点这里换成 Y」），一圈八档按顺序换，手动指定过的按钮文案会变成「恢复自动」，点一下就退回按名字自动配色；改名或合并分类时手动指定的颜色跟着搬过去。已完成的任务行不吃颜色（胶囊退回素色，免得灰掉的行上还挂着一块彩色），打印时颜色全部收口成黑白。这套颜色只是**给分类做数据编码**，页面主色仍然是那一条青绿，没有第二套强调色
- 搜索：列表上方「搜索任务或分类…」按关键词过滤任务文字与分类名（不区分大小写），与日期、分类筛选叠加生效；有内容时出现清除按钮，Esc 也能清空
- 看板视图：列表上方三颗按钮在「列表 / 看板 / 矩阵」之间切换，键盘按 `V` 也按这个顺序循环，选择会被记住。看板按当前清单里用过的分类分列，一条任务有几个分类就同时出现在几列，末尾固定一列「未分类」；列高一致，超长时各列自己滚动。按住卡片拖到另一列即可换分类——拖到某个分类列＝把这张卡上原来那一列的分类换成这一列、其他分类保留，拖到「未分类」＝摘掉这一列的分类，落在列与列之间的缝里则不改。点卡片回到列表并定位到它；换分类支持 6 秒撤销
- 矩阵视图：第三颗视图按钮切到四象限——「重要且紧急 · 先做」「重要不紧急 · 排期」「紧急不重要 · 尽快处理」「不重要不紧急 · 有空再说」。不另建字段：中 / 高优先级算重要，今天到期或已逾期算紧急，其余为不紧急；只放当前筛选下的未完成任务，已完成的任务不进矩阵。按住卡片拖到另一个象限即改属性：拖到「重要」把优先级设为高（本来就是中 / 高则不动），拖到「不重要」设为低；拖到「紧急」把到期日改成今天，拖到「不紧急」把逾期或今天到期改成明天。每次移动都记 6 秒撤销；卡片按置顶、到期日、优先级排序。点卡片或按 Enter 回到列表并定位到它；卡片获得焦点后按 `1`–`4` 可直接归到对应象限，焦点会留在原卡片上，方便连续调整。筛选把任务挡掉时，该象限只显示空态提示
- 拖拽排序：按住行左侧的把手上下拖动即可调整顺序，鼠标与手机触摸都支持；被筛选隐藏的项位置不变
- 任务置顶：点行右侧的图钉按钮把任务钉到列表最前面（再点一下取消，取消后它留在原位不再自动跳）；置顶的任务行会有一个黄色图钉标记，键盘模式下按 `P` 也能置顶 / 取消置顶当前选中的任务
- 今日专注 + 连续打卡：今日条显示「🔥 连续打卡 N 天」（每天至少勾完一项就算连着，今天还没完成不打断，从昨天往前数；断一天则重新计）和「今天要做 N 项」（今天到期 + 已逾期）；点「只看今日」只列出这两类任务，再点「退出今日专注」返回。开启时会自动把日期筛选切回「全部」，免得和「今天到期」叠加后列表空掉，状态会被记住。窗口宽到 1040px 以上时，整条今日专注会搬到右侧信息栏最上面的「今日专注」卡片里（三行数据各占一行、按钮铺满一行），窄下来又回到清单上方原来那条横条
- 备注与子任务：点行右侧的 ▾ 展开，可写最长 500 字的备注、勾加最长 120 字的子任务（回车即保存，可勾选、可删除）；收起后行上会留一个备注小图标（鼠标悬停看前 60 字）和一个「已完成 / 总数」进度标记；重复任务排出的下一条会带上同样的备注与子任务
- 勾选完成：文字加删除线，并进入「已完成任务历史」（记录完成时间，可按日期筛选、可折叠）
- 编辑任务：点行内 ✎ 或直接双击任务文字，回车保存、Esc 取消
- 删除单条、清空已完成、全部清空（后两者需二次确认）
- 误删可撤销：删除、清空已完成、全部清空、导入备份之后，屏幕下方会出现 6 秒的「↺ 撤销」条，点一下就把整份列表还原到操作之前，过期自动消失
- 恢复已完成：「已完成任务历史」里每条右侧多了一个 ↩ 按钮，点一下把这条任务放回未完成列表（会顺手清掉历史面板的日期筛选，免得放回的任务看不到）
- 「隐藏已完成任务」：点红色按钮，或点绿色的「已完成」统计卡片
- 统计卡片显示待完成 / 已完成数量，底部显示任务总数
- 数据统计：独立的「数据统计」卡片给出完成率、已逾期 / 今天到期 / 未来 7 天的数量，按分类与按优先级的完成进度条，近 7 天每天完成几个的柱状图（今天那根是绿色），以及本周小结与近 20 周打卡热力图；统计的始终是当前清单的全部任务，不受筛选影响；点右上角箭头可折叠，折叠状态会被记住
- 今日复盘：工具条右侧的「今日复盘」按钮（键盘 `R` 同效）按当前清单的真实数据生成一段 Markdown——标题带日期与星期，摘要写完成 / 未完成 / 逾期，有新建任务或番茄钟轮次时一并带上；今天有到期任务时再补一行「今日到期 x/y 已完成」。正文分「今天完成」（带完成时刻、优先级、最多 3 个分类、子任务进度与重复设置）、「还在路上」（已逾期 / 今天到期 / 其它高优先级）、「明天到期」，当天专注过再追加「今日专注」。文本在弹窗里可以直接改，改完能复制 Markdown、复制给 AI 润色的提示词（要求不编造数据、固定三段、每条动词开头、总长不超过 300 字），或下载成 `今日复盘-YYYY-MM-DD.md`；复制失败会提示手动全选。弹窗可点关闭 / 遮罩 / `Esc` 退出，关闭后焦点回到按钮；只统计当前清单，全程不联网
- 导出 / 导入备份：页面底部「⬇ 导出备份」把**所有清单**的任务、回收站和附件一起存成一个 JSON 文件，「⬆ 导入备份」从该文件恢复（导入会覆盖当前全部清单，会先弹确认，导入后 6 秒内可撤销；旧版备份和只有一份任务数组的老文件也照样能导，会并进「我的清单」）
- 到期提醒：有任务逾期时，列表顶部出现红色横幅「有 X 项已逾期，还有 Y 项今天到期」，带一个「只看逾期」按钮；也可以开启浏览器通知（每天最多弹一次，避免打扰）
- 精确提醒：展开任务详情，多一行提醒设置——用日期时间选择器挑一个具体时刻，点「设提醒」生效（快捷档「1 小时后 / 今晚 8 点 / 明天 9 点 / 明晚 8 点 / 下周一 9 点」只负责把时间填进选择器，任务有到期日时还会按剩余天数多出「到期前 3 天 / 到期前 1 天」，同样只是填值，都还要再点一下「设提醒」；选了已经过去的时间会就地提示，不会静默失效）。到点后页面最上方滑出一条黄色处置条，列出到点的任务，每条给「稍后 10 分钟」和「知道了」两颗按钮，多于一项时还有「全部知道了」，同时尝试发一条浏览器通知并「叮」一声。设了提醒的任务行上会挂一个铃声标记（写作「今天 15:30」「明天 9:00」「10月14日 20:00」），时刻已过还没处置的标记变红；日历的格子悬停提示里也会带上「N 项设了提醒」。提醒扫的是**所有清单**，在「生活」里设的提醒，哪怕正看着「工作」也照样弹，处置条上会标注「（在「生活」）」；弹过的记在本地不再重复骚扰，改了时刻则重新计；错过超过 3 小时就不再补弹。任务被勾完成、删掉、搬走或改了时间，处置条上那一条会自己消失，「知道了」则顺手清掉这条提醒

## 数据存储

全部数据保存在浏览器本机，不上传到任何服务器。`localStorage` 里：`todo.lists` 存清单名册（`{ v: 1, active, lists: [{ id, name }] }`），任务按清单分键存放——默认清单沿用老的 `todo.tasks`，其余清单是 `todo.tasks.<清单 id>`，所以老数据不需要迁移就会出现在「我的清单」里；`todo.prefs` 存偏好（筛选条件、是否隐藏已完成、今日专注开关、统计卡片折叠、视图列表 / 看板 / 矩阵、侧栏是否折叠、主题、背景配色、番茄钟时长、打印选项，以及手动指定过的分类颜色 `tagColors`），`todo.bgimg` 单独存自选的背景图（那串 base64 有几百 KB，分开存就不会在每次保存偏好时重写它），`todo.trash` 存回收站，`todo.pomo` 存今天的番茄钟轮数与休息次数（`{ day, n, br }`，换一天就重新计），`todo.reminded` 存已经弹过的精确提醒（`{ 任务id: 那次提醒的时刻 }`，只用来防止同一次提醒重复骚扰，清掉也不影响任务本身），`todo.seed` 只记录内置首批清单是否已导入过。任务的 `att` 字段只存附件的元数据（id / 文件名 / 类型 / 大小 / 时间），**文件本体存在 IndexedDB 的 `todo-files` 库、`files` 仓库里**（以附件 id 为键），图片附件另在同一个库的 `thumbs` 仓库里存一张最长边 160px 的 webp 缩略图（派生数据，不进备份）——`localStorage` 装不下二进制，而且每次保存任务都重写一遍 base64 会很慢。删附件、删任务、清空回收站之后，没人引用的文件与缩略图会在页面空闲时自动回收。注意 `localStorage` 和 IndexedDB 都按「协议+域名」隔离，本地双击打开与在线地址是两份互不相通的数据。换浏览器、换设备或清除浏览器数据都会导致任务与附件丢失；此页面没有账号与同步功能。需要长期保存或跨设备迁移时，用页面底部的「⬇ 导出备份」。

备份文件是标准 JSON（`{ app, version: 2, exportedAt, lists, trash, files? }`，缩进两格）。`lists` 是清单数组，每项 `{ id, name, tasks }`；`tasks` 里每条除了文字、优先级、到期日、分类、重复之外还带 `note`（备注）、`subs`（子任务数组，每项有 `text` 与 `done`）、`pin`（是否置顶）、`att`（附件元数据）、`focus`（在这项上跑满过几轮番茄钟）和 `remind`（精确提醒的时刻，毫秒时间戳，`0` 或没有这个字段就是不设提醒）。`files` 只在真有附件要打包时出现，形如 `{ "<附件 id>": { name, type, data } }`，`data` 是 base64 的 data URL；单个超过 2 MB 的附件、或打包后整体超过约 12 MB 时会留下不打包并在导出后提示「N 个大附件没打包」，这类附件只留在原机上。`version: 1` 的老备份（只有一包 `tasks`）甚至只有一份任务数组的更老文件都能直接导入，会被并进默认清单；缺 `note`/`subs`/`pin`/`att`/`focus`/`remind` 字段会补成默认值。导入时会校验字段形状，日期对不上下文的脏数据（如 `2026-13-45`）会被清成「无到期日」而不是顺延到别的日子，`focus`/`remind` 里的负数和非数字会被清成 0（`focus` 最多记到 999 轮），回收站里超过 30 天的条目导入时直接丢弃。

## 技术

纯 HTML + CSS + JavaScript，单文件，零依赖（无框架、无 CDN、无构建步骤）。图标为内联 SVG。附件的二进制内容用浏览器自带的 IndexedDB 存，因此「零依赖」仍然成立——没有任何外部脚本或字体。

配色集中在文件顶部 `:root` 的 CSS 变量里，分三层。最底是色阶：主色四档 `--teal-800: #115e59` / `--teal-700: #0f766e` / `--teal-600: #0d9488` / `--teal-50: #f0fdfa`；中性九档 `--gray-50`…`--gray-800`，浅色主题借用 Tailwind Gray（`#f9fafb` → `#1f2937`），深色主题用本套主题自己的青灰档（`#1d2c29` → `#e8f1ef`，深浅方向跟浅色主题相反，号越小越暗）；另外三组只用来编码数据：玫红（高优先级 / 危险操作 / 逾期）、琥珀（中优先级）、绿（低优先级 / 已完成）。中间是语义变量：`--surface`（实心底，浅 `#fff` / 深 `#172422`）、`--surface-glass`（玻璃卡片那层半透明底）、`--card-border`、`--card-sheen`（卡片顶边那条 1px 内高光）、`--btn-grad-a` / `--btn-grad-b`（渐变按钮的两端）、六档投影 `--shadow-card` / `-sm` / `-sm-hover` / `-btn` / `-btn-hover` / `-dialog`、`--scrim`、`--on-accent`（渐变按钮上的字色）、`--text-muted`（弱化文字那一档，见下面「外观层」）、`--page-bg`（指向成对的 `--bgl` / `--bgd`）、`--bg-wash`（自选背景图上的遮罩）。组件样式只引用这一层，不写死色号；`[data-theme="dark"]` 里把这两段整体重定义一遍，深色模式即整体反转，不必逐条改规则。同时设了 `color-scheme`，浏览器滚动条与表单控件会跟着换。想换整套配色，只改这两段的主色与由它推出来的档位即可。热力图用的四档色（`--hm0`–`--hm3`）也放在这两段里，浅色主题越深表示完成得越多、深色主题越亮表示完成得越多，空格子另有一圈 `--hm-line` 描边保证格子形状看得见。

外观这一版是第二十二版的薄荷玻璃样式层搬回第二十四版之上：DOM 与类名一行没改，动效层（进场曲线、逐字模糊、滚动揭示、点阵）一行没动，全部差异都落在 `:root` 那两段和若干条组件规则上。玻璃这层是带账的，账在三处：

- **半透明底不能直接读计算值**：卡片是 `--surface-glass`（浅 `rgba(255, 255, 255, .66)`、深 `rgba(20, 33, 31, .68)`）+ `backdrop-filter: blur(18px) saturate(1.5)`，全站 4 处玻璃（卡片 18px、遮罩 5px、弹层 12px、大图查看器 5px），每条都带 `-webkit-` 前缀，另加打印里那条复位（`grep -c backdrop-filter` = 9 行）。`getComputedStyle` 读到的 `backgroundColor` 只是那层膜，不是屏幕上真正那一层，所以对比度必须先把膜按 alpha 合成到真实底色（点阵最深那颗点 + 背景洗色）再算，见下面两段。
- **弱化文字统一走 `--text-muted`**：新增一档语义变量，两个主题都定义成 `var(--gray-600)`，并把原先直接写 `color: var(--gray-500)` 的 45 处换成它，第二十七版的新组件也接着用它（现在 `grep -c -- "--text-muted" index.html` = 56：两条注释 + 两条定义 + 52 处引用；`--gray-500` 只剩定义、零引用，仍留在色阶里）。这条不是预防性调整：把 `--text-muted` 临时改回 `var(--gray-500)` 再跑同一条探针，浅色主题红 **7 处**、最差 **3.05:1**（12px「键盘快捷键」露天压在 `#c8ced6` 那颗点上），深色主题红 **1 处**、最差 **3.71:1**；用 `--gray-600` 则同一批是 4.77 / 4.83，隔着玻璃膜的那批是 6.52 / 7.63。
- **标题与两处 teal 文字压暗一档**：浅色主题的渐变字原来是 `--teal-600 → #10b981 → --teal-700`，中间那颗绿 `#10b981` 压在白底上只有 2.54:1，本来就过不了 36px 粗体的 3:1 大字号门槛；这一版改成 `--teal-800 → --teal-700 → --teal-800`（`#115e59 → #0f766e`），逐字压在最深那颗点上实测 3.55–4.53。「新建清单」和菜单里两处 teal 文字同样从 `--teal-700` 提到 `--teal-800`。深色主题那条渐变没动。

### 动效与点阵背景

这一版的动效是照着参考站的做法重做的，四条纪律：进场只认一条曲线 `--ease-enter: cubic-bezier(.22, 1, .36, 1)`（配 `--dur-enter: .7s`），悬停一律裸 `.2s`，面板展开 `.3s`，全文 `ease-out` 出现 0 次（`grep -c "var(--ease-enter)" index.html` = 17 行，`grep -c ease-out` = 0）。标题逐字进场把 `h1` 的文本拆成 6 个 `.blur-text-segment`，每颗 `animation-delay` 递增加 80ms，`@keyframes blur-in` 三段式：0% `blur(10px)` / 下移 50px、50% `blur(5px)` / 上抬 5px、100% 归零，播完加 `.bt-done` 把 `filter` 整个撤掉——留着会让这六颗字长期吃一层 GPU 滤镜。

玻璃那版给这条动效添了一个只有实测才会撞上的坑：**祖先链上只要出现 `background-clip: text`，子元素的 `filter` 就不起作用**。标题正是渐变字，拆成六颗 span 后加 blur，截图里糊不出来（`filter` 被算进样式却画不出来）；换一种写法（让每颗字自己继承渐变）更糟，`color: transparent` 会把整条标题直接抹没。现在的做法是拆字时先用一条 `.head h1.blur-text { background: none; background-clip: border-box }` 把渐变关掉，再由脚本读同一条渐变的三个色标，按每个字在标题里的水平位置插值取色，主题切换时用 `MutationObserver` 重取一次——渐变留不住形状，留得住观感（逐字取到的色就是 `#11625c`…`#0f746c` 这一列，实测数字见下面两段）。顺带修掉一个上一版就带着的毛病：`.bt-done` 原先撤不掉 `filter`，因为 `animation ... both` 的填充模式会永久压过它，现在最后一颗字播完时先摘 `bt-run` 再加 `bt-done`。

滚动揭示用 `IntersectionObserver`，参数 `{ threshold: .12, rootMargin: '0px 0px -40px 0px' }`，命中即加 `.visible` 并 `unobserve`，所以只播一次、往回滚不重播。这里有个必须记住的坑：**「把内容藏起来」这件事只认 `html.reveal-on` 这个类，而这个类由脚本在观察器挂好之后才加**。整页只有一个 `<script>`，前面任何一句抛错都会让这段跑不到；要是 CSS 无条件就把 `.reveal` 设成 `opacity: 0`，用户看到的就是三块永久空白。所以顺序是「先挂观察器 → 再放行首屏内已有的块 → 最后 `add('reveal-on')`」，外面还包一层 `try/catch` 兜底 `showAll()`；减弱动效或浏览器没有 `IntersectionObserver` 时直接 `showAll()` 且不加那个类。打印路径另有一道 `!important` 复位（`html.reveal-on .reveal { opacity: 1 !important; transform: none !important }`），实测用 CDP 的 `Emulation.setEmulatedMedia({ media: 'print' })` 切媒体：说明站第一屏外那张卡在屏幕媒体下是 `opacity: 0 / translateY(28px)`，切到 print 变成 `1 / none`，切回来又回到 `0`。折叠面板也不打架：`#history` 是 `display: none`，展开后观察器照样补上 `.visible`（实测 `op` 从 0 变 1）。

点阵背景是一块 `position: fixed; z-index: -1; pointer-events: none` 的 canvas，`aria-hidden`，参数与参考站一致：点径 5px、间距 15px、邻近半径 120px、触发速度 100px/s、冲击半径 250px、强度 5、最大速度 5000、回位 1500ms；弹簧用 `1 - Math.pow(1 - p, 3) * Math.cos(p * 4.5)`，180ms 推开 + 200ms 延迟 + 1500ms 回位，`mousemove` 50ms 节流，DPR 缩放 + 一个共享 `Path2D` + `ResizeObserver`。两点与参考站不同，都是量出来的决定：一是**点击涟漪加了闸门**——参考站是登录页，点哪儿都算背景，而这是清单页，一天要勾几十次完成框，所以落在 `.card, .head, button, a, input, select, textarea, label, li` 上的点击不起涟漪；二是**点不带色相**，深浅两主题各只有一对 `--dot-base` / `--dot-hot`（浅 `#d4d9df` / `#c8ced6`，深 `#27272a` / `#4a4a52`），效果全靠运动本身。

物理指标不能在有头浏览器里量（虚拟时间会饿死 `requestAnimationFrame`，CSS 过渡和观察器回调也一样饿），所以把引擎原样抽进 Node 用可控时钟逐帧驱动，稳定复现：1280×900 共 2880 个点，静置 90 帧重绘 **0** 次（空闲不烧 CPU）；快速划过时最多 224 个点被推开、峰值位移 149.4px、出现在第 83ms、随后回到原位（峰值位移 0）；空白处点击涟漪带动 484 个点、峰值 336.1px；**点在卡片上时重绘 0 帧、位移 0**（闸门生效）；慢速移动（10px/s）不推点，只让邻近点变色——同一帧里出现 18 种颜色、无指针时只有 1 种，说明按距离做了插值。减弱动效下重跑同一套：位移与涟漪全为 0，只保留点亮。

页面背景是 `--page-bg`，它指向成对的 `--bgl`（浅色版）与 `--bgd`（深色版），预设配色只是用 `[data-bg="mist"]` 这类选择器把这一对变量整体换掉，所以新增一套预设仍然只要写两条背景。这两条现在都是四层叠起来的：三团主题色的 `radial-gradient` 光斑（左上、右上、底部中央）压在一层 `linear-gradient(165deg, …)` 基础渐变上，光斑的透明度浅色主题在 `.12`–`.24` 之间、深色主题在 `.08`–`.14` 之间，基础渐变的明暗区间和上一版一致，因此换成光斑背景不会整体变亮或变暗。背景面板里那九个色板方块就是把 `--bgl` / `--bgd` 原样画成自己的背景（`[data-theme="dark"] .sw .sw-c` 用 `--bgd`），预设改了色板自动跟着改，不用另写一份颜色。面板本身要在页头这一层（`z-index: 41`）：玻璃卡的 `backdrop-filter` 会各自形成层叠上下文，不把页头抬起来，面板就会被右侧卡片盖住。自选图片走另一条路：`html[data-bgimg="1"] body::before` 一层 `position: fixed` 的图，上面叠一层 `--bg-wash`（浅色主题 `rgba(255, 255, 255, .8)`、深色主题 `rgba(8, 14, 13, .8)`），最暗的图配浅色、最亮的图配深色这两种极端情况都仍满足下面的对比度要求。

两套主题、九套预设、以及压在最暗 / 最亮图片上的情况都按 WCAG AA 校验过：文字对比度不低于 4.5:1，图标与非文字控件不低于 3:1。玻璃这层的量法和实面那版不一样：`getComputedStyle` 读到的 `backgroundColor` 是半透明的膜，不能直接当结论，所以探针从元素自己往上走，把一路上所有带 alpha 的层按合成公式叠到「这块区域底下真正不透明的那一层」上——露天的文字叠到点阵最深那颗点 `--dot-hot`，卡片里的文字先叠背景洗色再叠玻璃膜；渐变字与渐变按钮这类计算值是 `transparent` 的，取它渐变色标上的实色来算。跑 `node aa28.tmp.mjs`（2 主题 × 9 预设共 18 组，每组在 1280×900 下测 284 个文字元素）：**18 组全部 0 处不达标**。浅色最差 3.42:1（液态玻璃）/ 3.53:1（紫雾）/ 3.55:1（其余七套），都是 36px 粗体标题里最亮那颗字，走 3:1 的大字号门槛；深色最差 4.72:1。每组还把当时的点阵两档色与洗色一起打印出来，便于复核。窄视口另跑 `node aa-narrow.tmp.mjs`：390×844 与 320×700 各 47 个文字元素，两个主题同样 0 处不达标，最差值与宽屏一致。自选背景图那一层挂在 `body::before` 上，探针从元素链里读不到，所以 `node aa-img.tmp.mjs` 在页面里现场生成纯色图（最暗 `#000` 与最亮 `#fff` 两个极端），按应用自己的写法挂上 `--bg-img` 与 `--bg-wash`，再把「遮罩合成到图上」的结果交给同一条探针：浅色主题压最暗的图合成 `rgb(204, 204, 204)`，最差 3.50:1（仍是那颗标题字，走 3:1）；压最亮的图合成纯白，最差 3.55:1；深色主题两种合成都很暗（`rgb(6, 11, 10)` / `rgb(57, 62, 61)`），最差 4.72:1——四组各 50 个元素，**0 处不达标**。第二十八版又用液态玻璃把 6 个状态跑了一遍（两主题 × 列表 / 大图 / 看板），每组 247–286 个文字元素，同样 **0 处不达标**，最差仍是那颗标题字（浅 3.42 / 深 4.72）。可点区域没有因为新组件而缩水：`min-height: 44px` 现在是 40 处，主控件仍保持 44px 命中区；两处密排例外是附件行的 `.fbtn`（36px）与任务行小缩略图（26px），大图查看器的翻页键 `.av-btn` 则是 44px。1280 / 900 / 390 / 360 宽实测页面无横向溢出（看板超出时在列条内部横向滚动），390 宽下背景面板的 9 个色板也全在视口内。第二十九版把矩阵与今日复盘也交给同一条探针：2 主题 × 矩阵 / 复盘 / 液态玻璃下的复盘共 6 组，每组 273–292 个文字元素，**0 处不达标**，最差仍是那颗标题字（浅 3.55、液态玻璃 3.42，深 4.72）。

点阵是最花的一层背景，玻璃膜又只有 .66 / .68，所以「这行字到底压在什么上面」得一个个认。量法不是猜，而是遍历 `body` 下每个有直接文字节点、且已渲染的元素，从它自己往上找有没有一层不透明的底把点阵挡住——挡不住的按「最深那颗点 + 它上面那层膜」算（点径 5px、间距 15px，覆盖率不到 5%，按整片都是深点算是最坏情况），`node aadots.tmp.mjs` 把这一档单独列出来。结果：两个主题各 **35 处**文字与点阵合成，其中 **10 处露天**（标题六个字、副标题、「共 N 个任务」、「新建清单」、「键盘快捷键」），另外 **25 处隔着一层玻璃膜**（录入卡的标签与提示、统计卡的小字、备份三颗按钮、空状态标题等）。最差的是露天那批：浅色 3.55–4.79（标题六个字 3.55–4.53 走 3:1 大字号门槛，16px 副标题与 12px 按钮 4.77 走 4.5），深色 4.72–6.96（标题 4.72–5.75，副标题与按钮 4.83）；隔着膜的那 25 处最暗一档是 `--text-muted` 的 6.52（浅）/ 7.63（深），统计卡两个大数字 4.33 与 4.72（浅，24px 粗体走 3:1）、7.96 与 9.38（深）。任务行、弹层正文这些落在实心 `--surface` 上的，压根不和点阵重叠。

版式用的是第三层「组件变量」：`--wrap-narrow`（单栏上限 768px）、`--wrap-wide`（双栏总宽 1132px）、`--side-w`（信息栏宽度 `clamp(280px, 26vw, 340px)`）、`--dash-gap`、`--card-gap`、`--sticky-top`，只放尺寸不放颜色，改栏宽只动这一处。两栏由 `.dash { display: grid }` 承担：默认单列，`@media (min-width: 1040px)` 才变成 `minmax(0, 1fr) var(--side-w)`，`.side` 上 `position: sticky` + `max-height: calc(100vh - 32px)` + `overflow: auto`。踩到过几个坑，都在这里记一笔：一是**网格项的 `min-width` 默认是 `auto`**，信息栏里的统计卡会被热力图、四格指标这些「压不窄」的内容撑到 363px，直接顶破 340px 的轨道（页面不出现横向滚动条，只在栏内悄悄多出一条滚动），所以 `.dash > *` 与 `.side > *` 都显式写了 `min-width: 0`；二是**日历不能搬进信息栏**——七列网格在 300px 宽的栏里每格只剩三十几像素，所以两栏里它留在主栏，右侧只放今日专注、统计与历史；三是**同一块 UI 不能有两份 DOM**，所以「今日专注」只有一个 `#today-strip`，由 `matchMedia('(min-width: 1040px)')` 在两个父节点之间搬（宽屏进 `#focus-card`，窄屏插回清单卡片的筛选条前面），搬完再 `render()` 一次同步卡片的显隐——横条里的番茄钟下拉原本是 `position: absolute` 挂在横条下面的，搬进信息栏就会被 `.side` 的 `overflow: auto` 裁掉，所以宽屏下改成 `position: static` 就地展开成一行。打印时 `.dash` 复位成 `display: block`、`.side` 连同里面的今日专注一并隐藏，输出的还是纯清单。

看板与侧栏折叠各有一条布局规则。看板是一条 `display: flex; align-items: stretch` 的横向列条（`max-height: 66vh`，超出横向滚动），每列 `flex: 0 0 min(264px, 78vw)` 且自己 `overflow: auto`——列高由同一行里最高的那列拉齐，短列不会在下面留出一片空白；`html[data-view="board"]` 时 `#list` 被藏起、`.board` 显示，打印则用 `#list { display: block !important }` 把它拉回来。侧栏折叠只写在 `@media (min-width: 1040px)` 档内：`html[data-side="off"] .dash` 收成一列、`.side` 整块 `display: none`，窄屏本来没有独立侧栏，工具条上那颗 `.side-toggle` 也不显示；状态存在 `prefs.sideCollapsed`，刷新后由 `syncSide()` 还原，按钮的 `aria-pressed` 跟着变。

矩阵是 `grid-template-columns: repeat(2, minmax(0, 1fr))` 的 2×2 网格，四个 `.mx-q` 各自是一张玻璃卡，卡与卡之间留 14px；`html[data-view="matrix"] #list { display: none }`，打印则和看板一样把 `.matrix` 收进隐藏清单，永远输出列表。窄屏 365px 下四格各约 157.5px，页面 `scrollWidth` 仍是 365，不出现横向溢出；象限里的卡片沿用看板的 `.bd-card`，只是多一行优先级 / 到期日元信息，拖动阈值仍是 6px，落点按列矩形判定。今日复盘用的是 `.dialog.review-dialog` 加一个可编辑的 `<textarea>`，在 365×740 的视口里弹窗左右 16–349px、高约 608px，文本框 `min-height: clamp(200px, 46vh, 360px)`，内容再多也在框内滚动；关闭、遮罩与 `Esc` 走同一条 `openReview(false)`，焦点回到工具条按钮。

### 分类配色

八个色相，每个色相**一个主题只有一个值**：`--tag-blue` / `--tag-amber` / `--tag-violet` / `--tag-rose` / `--tag-green` / `--tag-indigo` / `--tag-sky` / `--tag-slate`，浅色主题那组是压暗的 800 档（`#1e40af` … `#334155`），深色主题那组是提亮的 300 档（`#93c5fd` … `#cbd5e1`），`[data-theme="dark"]` 里整段重定义，所以 `grep -c -- "--tag-" index.html` = **24**（16 条定义 + 8 条 `.c-*` 赋值）。同一个值既当胶囊的字色，也当小圆点的填充色，不再分「字用深一档、点用浅一档」——分档就要各测两遍，而这一档在两个主题里都能同时过 4.5 与 3。静态算（`node tagcolor-calc.tmp.mjs`，字与淡底都先按 alpha 合成到玻璃底下那颗最深的点再算）：浅色最低 **5.05:1**（violet 的字）/ 色点最低 **6.1:1**（amber），深色最低 **5.46:1**（indigo 的字）/ 色点最低 **6.97:1**，8 个色相 × 2 主题 × 2 用途（字 / 点）共 32 个数，全部过线。

挂色的方式是**一层自定义属性间接**：`.c-blue` 这类类名只干一件事——把 `--tg` 设成对应色相；所有消费方（`.tg`、`.tchip`、`.tchip-x`、`.tdot`、`.tagm-row .tm-name svg`）读的是 `var(--tg, 兜底色)`。这样加一处消费点不用碰色相表，也避免用一堆同权重的选择器互相抢；最要紧的好处是**已完成行能一处收口**：`.done .tg { color: var(--text-muted); --tg: transparent }`，`--tg` 一收，字色、淡底、描边三处同时退回素色，不用逐条写覆盖。

淡底与描边用 `color-mix(in srgb, var(--tg, transparent) 12% / 34%, …)`，写成「先给一条纯色兜底、再给一条 color-mix」的顺序（全文 `color-mix` 共 3 处）：认不得这个函数的老浏览器停在纯色那行，损失的只是那层淡底，字色照常。这是渐进增强，不是兼容补丁——新浏览器读到的是后一条。

颜色是**数据编码，不是第二套强调色**，所以主色那条青绿、渐变按钮、`--on-accent` 一概没动；分类色也不进备份文件（它跟着 `todo.prefs` 走，而 `prefs` 和主题、背景图一样被排除在导出 JSON 之外）——换设备后颜色会按分类名自动重算回来，手动指定过的那几个要重新点一下。

实测分两条 CDP 探针（无头 Edge，`Emulation.setEmulatedMedia` 切 `prefers-color-scheme`）：`node aa-run.tmp.mjs` 遍历「有直接文字节点且已渲染」的元素算文字对比，`node aa-dots.tmp.mjs` 遍历每个 `.tdot` 按非文本 3:1 算色点对它底下那层底的对比。2 主题 × 3 状态（首屏 / 展开一条任务详情 / 打开管理分类面板）× 2 视口（1280×900 与 320 宽）共 **12 组，0 处不达标**：文字每组 276–333 个，全组最低仍是那颗 36px 粗体标题字（浅 3.55 / 深 4.72，走 3:1 大字号门槛）；色点每组 14 个（打开面板后 21 个），最低浅 **6.12**、深 **6.96**。自选背景图那两个极端另跑 `node aa-img.tmp.mjs`（纯黑图 / 纯白图 × 两主题共 4 组，遮罩 `--bg-wash` 合成后交给同两条探针），同样 **0 处不达标**，色点最差的一组是浅色压最暗的图（合成 `rgb(204, 204, 204)`）6.09。打印收口不是「写着像对」：`node print.tmp.mjs` 用 `Emulation.setEmulatedMedia({ media: 'print' })` 真切媒体后读计算值，`.tg` / `.tchip` / `.tchip-x` 三处都变成 `rgb(0, 0, 0)` 压 `rgb(255, 255, 255)`、`.tdot` 的 `display` 变 `none`，切回屏幕媒体又恢复彩色。第二十七版另用同一招在**看板视图**下切 print：`#list` 计算值为 `block`，看板 / 视图切换条 / 行上缩略图 / 附件大图 / 侧栏 / 页头 / 工具条全部 `none`，`body` 白底、任务行黑字。

踩到的坑记一笔：详情里那颗删分类的 × 本来写的是 `.tchip-x { color: var(--tg, …) }`，可它外面那条 `.tags-edit button`（权重 0,1,1）把它（0,1,0）压死了，颜色根本不生效——截图里看不出来，是探针把计算值打出来才发现的，所以这两条最终写成 `.tags-edit .tchip-x`。
