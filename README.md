# 我的待办清单

一个单文件的待办事项网页：打开即用，不需要安装、不需要联网、不需要构建。

## 用法

- 直接下载 `index.html` 双击用浏览器打开；或
- 访问 GitHub Pages 部署后的在线地址（见下方「开启 GitHub Pages」）

## 功能

- 添加任务，回车或点击「➕ 添加任务」
- 优先级：高 / 中 / 低，用不同颜色标识，添加前在「优先级」处选择
- 到期日：添加时可选填「到期日」（也可在编辑时改），列表上显示「逾期 N 天 / 今天到期 / N 天后到期 / 10/14 到期」，逾期为红色
- 重复任务：给任务设置「每天 / 每周 / 每月」，勾选完成后会自动排出一条下一次的任务（到期日顺延；已经逾期的从今天往后推，不背旧账；每月按当月末日夹紧；没填到期日的重复任务照样重新排出一条）。完成的那条仍保留在历史里参与统计，列表上重复任务带循环图标标记
- 按日期筛选：全部 / 已逾期 / 今天到期 / 未来 7 天 / 无日期，筛选结果计数显示在按钮上，选择会被记住
- 分类 / 标签：给任务打一个分类（如 学习 / 生活 / 考证），输入框会联想已有分类、输入新名字即新建；列表上方「按分类筛选」可切换，计数与日期筛选叠加生效；自带的首批清单已按 自媒体 / AI工具 / 项目开发 / 考证备考 / 理财赚钱 / 健康形象 / 生活杂事 分好类
- 搜索：列表上方「搜索任务或分类…」按关键词过滤任务文字与分类名（不区分大小写），与日期、分类筛选叠加生效；有内容时出现清除按钮，Esc 也能清空
- 拖拽排序：按住行左侧的把手上下拖动即可调整顺序，鼠标与手机触摸都支持；被筛选隐藏的项位置不变
- 勾选完成：文字加删除线，并进入「已完成任务历史」（记录完成时间，可按日期筛选、可折叠）
- 编辑任务：点行内 ✎ 或直接双击任务文字，回车保存、Esc 取消
- 删除单条、清空已完成、全部清空（后两者需二次确认）
- 「隐藏已完成任务」：点红色按钮，或点绿色的「已完成」统计卡片
- 统计卡片显示待完成 / 已完成数量，底部显示任务总数
- 数据统计：独立的「数据统计」卡片给出完成率、已逾期 / 今天到期 / 未来 7 天的数量，按分类与按优先级的完成进度条，以及近 7 天每天完成几个的柱状图（今天那根是绿色）；统计的始终是全部任务，不受筛选影响；点右上角箭头可折叠，折叠状态会被记住
- 导出 / 导入备份：页面底部「⬇ 导出备份」把全部任务存成一个 JSON 文件，「⬆ 导入备份」从该文件恢复（导入会覆盖当前任务，会先弹确认）
- 深色模式：标题右上角的圆形按钮三态切换「跟随系统 → 浅色 → 深色」，跟随系统时按系统的深浅偏好自动变化；选择会被记住，下次打开在渲染前就定好主题，不会闪白
- 响应式：手机上输入框与按钮竖排，所有可点区域不小于 44px

## 数据存储

全部数据保存在浏览器本机的 `localStorage`，不上传到任何服务器：`todo.tasks` 存任务，`todo.prefs` 存偏好（筛选条件、是否隐藏已完成、统计卡片折叠、主题），`todo.seed` 只记录内置首批清单是否已导入过。注意 `localStorage` 按「协议+域名」隔离，本地双击打开与在线地址是两份互不相通的数据。换浏览器、换设备或清除浏览器数据都会导致任务丢失；此页面没有账号与同步功能。需要长期保存或跨设备迁移时，用页面底部的「⬇ 导出备份」存一份 JSON 文件，再在另一台设备上「⬆ 导入备份」。

## 技术

纯 HTML + CSS + JavaScript，单文件，零依赖（无框架、无 CDN、无构建步骤）。图标为内联 SVG。

配色集中在文件顶部 `:root` 的 CSS 变量里：色阶为主色青绿（`--teal-*`），语义色为玫红（高优先级 / 危险操作 / 逾期）、琥珀（中优先级）、深绿（低优先级 / 已完成），背景是浅青渐变。样式不直接写死色号，而是用一层语义变量（`--surface`、`--card-border`、`--page-bg`、`--on-accent`、`--shadow-*`、`--scrim` 等）引用色阶；`[data-theme="dark"]` 里把这一整套变量重定义一遍，深色模式即整体反转，不必逐条改规则。同时设了 `color-scheme`，浏览器滚动条与表单控件会跟着换。想换整套配色，只改 `:root` 与 `[data-theme="dark"]` 这两段即可。

两套主题下的正文、次要文字、占位符与图标都按 WCAG AA 校验过：文字对比度不低于 4.5:1，图标与非文字控件不低于 3:1。

## 开启 GitHub Pages

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. **Build and deployment** → Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 **`/ (root)`** → **Save**
4. 等待约 1 分钟，页面顶部出现地址：`https://<你的用户名>.github.io/<仓库名>/`
