# 我的待办清单

一个单文件的待办事项网页：打开即用，不需要安装、不需要联网、不需要构建。

## 用法

- 直接下载 `index.html` 双击用浏览器打开；或
- 访问 GitHub Pages 部署后的在线地址（见下方「开启 GitHub Pages」）

## 说明站

仓库里另有一份讲这个页面的说明小站，同样零依赖、零 CDN、双击 `网站/index.html` 即开（在线：`https://<你的用户名>.github.io/<仓库名>/网站/`）：

- **总览**（`网站/index.html`）：一页看清它有哪些能力，页面上的数字（模块数、功能条数、常量数、泳道数、方块数、连线数）是运行时从 `网站/assets/data.js` 的数组长度算出来的，不是手写死的。
- **功能清单**（`网站/功能清单.html`）：按页面区块归纳成 8 个模块共 39 条能力，左侧目录可跳转并随滚动高亮，顶部搜索框按关键词逐条过滤。
- **业务流程图**（`网站/业务流程图.html`）：7 条泳道、45 个方块、56 条连线（其中 21 条带标签）的完整流程图，可缩放、可点选方块高亮相关连线、可打印。
- **数据与架构**（`网站/数据与架构.html`）：6 条存储与边界说明 + 15 行关键常量，每行第三列给的是源码里的依据。

全站支持浅色/深色，主题偏好存在 `localStorage` 的 `flowdoc.theme`，和待办页自己的 `todo.*` 键互不影响。描述一律以线上 `index.html` 源码为准，不含推测。

## 功能

- 添加任务，回车或点击「➕ 添加任务」
- 多清单分开：清单以标签页的形式排在输入框上方（每个标签带一个「还剩几件待办」的小角标），点一下就整页换成那个清单的任务。点「＋ 新建清单」新建（最多 12 个、名字最多 12 个字），点右侧的「⋯」可以重命名或删除当前清单——删除时里面的任务会先进回收站（30 天内还能恢复），其他清单不受影响，且至少会留一个清单。默认那个清单沿用老键名，所以升级前存下的任务会原样出现在「我的清单」里，不需要迁移。快速添加、筛选、统计、日历、回收站都只看当前清单，切来切去互不干扰
- 任务跨清单搬运：展开任意一条任务的详情，下面有一行「移到其他清单…」的下拉，选中就搬过去——备注、子任务、附件、置顶、重复、提醒都一起带走，6 秒内可撤销；批量管理里选中多项后，工具条上同一颗下拉可以一次搬好几条。只有一份清单时这两处都不会出现（批量那颗会置灰）
- 清单排序：输入框上方那排清单标签可以直接按住往左右拖，拖动时会在该落下的位置显示一条竖线，松手即生效；手机上同样能拖。位移不到 6 个像素仍算「点开这个清单」，不会误改顺序
- 批量粘贴建任务：在输入框里直接粘贴一段多行文字（用换行、`、`、`，`、`,`、`；`、`;` 分隔都行），会自动弹出「批量添加」面板；也可以点输入框下方的「⧉ 批量粘贴」手动展开。每一行变成一条待确认的任务，面板里能逐行看到结果、点 × 删掉不要的，行内照样认 `#分类`、`!高`、`@周五`、`~每周` 这套快速添加语法；没写属性的行会沿用上方当前选好的优先级、到期日、分类、重复。一次最多 50 条，超出的会截断并提示。点「添加这 N 条」一次性入库（支持 6 秒撤销），`Ctrl+Enter` 等同于点添加，`Esc` 收起
- 任务附件：展开任务详情，最下方是「附件」区，点「 添加附件」选文件（可多选）就能挂到这条任务上。每条任务最多 8 个附件、单个最大 5 MB，行上会显示文件名、大小和「下载」「删除」两个按钮，收起详情后任务行上留一个回形针标记。附件本体存在浏览器本地的 IndexedDB（`todo-files`）里，不上传到任何服务器，任务数据本身只记一条文件名/大小的元数据；删掉附件或删掉任务后，对应的文件会在页面空闲时自动回收，回收站里还留着的任务其附件不会被回收。要带到别的设备上，用页面底部的「⬇ 导出备份」，附件会一起打包进 JSON（见「数据存储」）
- 打卡热力图与本周小结：「数据统计」卡片底部新增两块。「本周小结」用四个格子给出本周完成数、比上周多/少几个、这周有几天打了卡、最活跃是星期几，下面一句话带上连续打卡天数。「打卡热力图」是近 20 周、周一开头的方格图（一格一天，颜色越深当天完成得越多，还没到的日子留空，今天带一圈描边），鼠标悬停能看到「10月8日：完成 2 个」。两块都按任务的完成时间统计，一条完成记录都没有时自动隐藏，不影响折叠
- 一句话快速添加：在输入框里一行写完，用符号带出属性——`#分类`、`!高`/`!中`/`!低`（`!高优先` 这种写法也认）、`@今天`/`@明天`/`@后天`/`@大后天`/`@周五`/`@下周三`/`@10-20`/`@2026-10-20`、`~每天`/`~每周`/`~每两周`/`~每月`。不带符号的自然说法（「明天」「每周一」「10-20」）也认，全角符号（`＃！＠～`）同样有效。输入时会有一行提示实时显示识别结果，认不出来的部分照原样当任务名。示例：`写周报 #工作 !高 @周五 ~每周`
- 优先级：高 / 中 / 低，用不同颜色标识，添加前在「优先级」处选择；快速添加里的 `!高` 会覆盖这里的默认选择
- 到期日：添加时可选填「到期日」（也可在编辑时改），列表上显示「逾期 N 天 / 今天到期 / N 天后到期 / 10/14 到期」，逾期为红色
- 重复任务：给任务设置「每天 / 每周 / 每月」，勾选完成后会自动排出一条下一次的任务（到期日顺延；已经逾期的从今天往后推，不背旧账；每月按当月末日夹紧；没填到期日的重复任务照样重新排出一条）。完成的那条仍保留在历史里参与统计，列表上重复任务带循环图标标记
- 按日期筛选：全部 / 已逾期 / 今天到期 / 未来 7 天 / 无日期，筛选结果计数显示在按钮上，选择会被记住
- 分类 / 标签：给任务打分类，最多 4 个（输入框会联想已有分类、输入新名字即新建，空格 / 逗号 / 顿号分隔可一次填多个）；列表上方「按分类筛选」可切换，计数与日期筛选叠加生效；快速添加里连写 `#工作 #学习` 可一次打两个分类；自带的首批清单已按 自媒体 / AI工具 / 项目开发 / 考证备考 / 理财赚钱 / 健康形象 / 生活杂事 分好类
- 分类管理：「按分类筛选」那一行最右边多了一颗虚线框的「管理分类」，点开是一个面板，把用过的分类按字母顺序列出来，每条写着「N 项待完成 · M 项已完成」，右侧三颗操作：「改名」（行内变成输入框，回车或点「保存」；改成已经存在的名字就等于合并这两个分类）、「合并到…」下拉（只有一个分类时禁用）、「去掉标记」（从所有任务上摘掉这个分类，任务本身一条都不删）。这些改动在**所有清单**里一并生效，回收站里躺着的那些年同名分类也跟着改；改完 6 秒内可撤销。面板上的数量只数各清单的任务，不含回收站
- 搜索：列表上方「搜索任务或分类…」按关键词过滤任务文字与分类名（不区分大小写），与日期、分类筛选叠加生效；有内容时出现清除按钮，Esc 也能清空
- 拖拽排序：按住行左侧的把手上下拖动即可调整顺序，鼠标与手机触摸都支持；被筛选隐藏的项位置不变
- 任务置顶：点行右侧的图钉按钮把任务钉到列表最前面（再点一下取消，取消后它留在原位不再自动跳）；置顶的任务行会有一个黄色图钉标记，键盘模式下按 `P` 也能置顶 / 取消置顶当前选中的任务
- 今日专注 + 连续打卡：列表上方的今日条显示「🔥 连续打卡 N 天」（每天至少勾完一项就算连着，今天还没完成不打断，从昨天往前数；断一天则重新计）和「今天要做 N 项」（今天到期 + 已逾期）；点「只看今日」只列出这两类任务，再点「退出今日专注」返回。开启时会自动把日期筛选切回「全部」，免得和「今天到期」叠加后列表空掉，状态会被记住
- 备注与子任务：点行右侧的 ▾ 展开，可写最长 500 字的备注、勾加最长 120 字的子任务（回车即保存，可勾选、可删除）；收起后行上会留一个备注小图标（鼠标悬停看前 60 字）和一个「已完成 / 总数」进度标记；重复任务排出的下一条会带上同样的备注与子任务
- 勾选完成：文字加删除线，并进入「已完成任务历史」（记录完成时间，可按日期筛选、可折叠）
- 编辑任务：点行内 ✎ 或直接双击任务文字，回车保存、Esc 取消
- 删除单条、清空已完成、全部清空（后两者需二次确认）
- 误删可撤销：删除、清空已完成、全部清空、导入备份之后，屏幕下方会出现 6 秒的「↺ 撤销」条，点一下就把整份列表还原到操作之前，过期自动消失
- 恢复已完成：「已完成任务历史」里每条右侧多了一个 ↩ 按钮，点一下把这条任务放回未完成列表（会顺手清掉历史面板的日期筛选，免得放回的任务看不到）
- 「隐藏已完成任务」：点红色按钮，或点绿色的「已完成」统计卡片
- 统计卡片显示待完成 / 已完成数量，底部显示任务总数
- 数据统计：独立的「数据统计」卡片给出完成率、已逾期 / 今天到期 / 未来 7 天的数量，按分类与按优先级的完成进度条，近 7 天每天完成几个的柱状图（今天那根是绿色），以及本周小结与近 20 周打卡热力图；统计的始终是当前清单的全部任务，不受筛选影响；点右上角箭头可折叠，折叠状态会被记住
- 导出 / 导入备份：页面底部「⬇ 导出备份」把**所有清单**的任务、回收站和附件一起存成一个 JSON 文件，「⬆ 导入备份」从该文件恢复（导入会覆盖当前全部清单，会先弹确认，导入后 6 秒内可撤销；旧版备份和只有一份任务数组的老文件也照样能导，会并进「我的清单」）
- 到期提醒：有任务逾期时，列表顶部出现红色横幅「有 X 项已逾期，还有 Y 项今天到期」，带一个「只看逾期」按钮；也可以开启浏览器通知（每天最多弹一次，避免打扰）
- 精确提醒：展开任务详情，多一行提醒设置——用日期时间选择器挑一个具体时刻，点「设提醒」生效（「1 小时后」「明天 9 点」两颗快捷按钮只负责把时间填进选择器，还要再点一下「设提醒」；选了已经过去的时间会就地提示，不会静默失效）。到点后页面最上方滑出一条黄色处置条，列出到点的任务，每条给「稍后 10 分钟」和「知道了」两颗按钮，多于一项时还有「全部知道了」，同时尝试发一条浏览器通知并「叮」一声。设了提醒的任务行上会挂一个铃声标记（写作「今天 15:30」「明天 9:00」「10月14日 20:00」），时刻已过还没处置的标记变红；日历的格子悬停提示里也会带上「N 项设了提醒」。提醒扫的是**所有清单**，在「生活」里设的提醒，哪怕正看着「工作」也照样弹，处置条上会标注「（在「生活」）」；弹过的记在本地不再重复骚扰，改了时刻则重新计；错过超过 3 小时就不再补弹。任务被勾完成、删掉、搬走或改了时间，处置条上那一条会自己消失，「知道了」则顺手清掉这条提醒
- 日历月视图：独立的「日历视图」卡片，周一开头；格子上角标当天共几件（红点 = 逾期，青点 = 当天到期，绿点 = 当天完成过）；点某一天，清单就只看那天到期的任务（再点一下取消），点「＋」直接添加那天的任务，也有「回到本月」
- 回收站：删除的任务先进回收站，保留 30 天、上限 200 条，随时可恢复或彻底清空；备份文件也会带上回收站内容
- 番茄钟：今日条上的「番茄钟 25 分钟」一键开始专注倒计时，标题栏同步显示剩余时间，完成后「叮」一声并计入「今日专注 N 轮」；时长可改——点旁边的 ▾ 在 25 / 45 / 60 分钟里选，或在「5–120」里填自定义分钟数，选择会被记住
- 专注后的休息：一轮专注跑完会弹出「这一轮完成了」，给「开始休息 5 分钟」和「跳过这次休息」两个选择；休息计时中今日条上的按钮变绿并显示「休息 MM:SS · 点击结束」，跑完再弹「休息结束了」问要不要开始下一轮。休息满一次计入「今日专注 N 轮 · 休息 M 次」，提前点结束则不计；两条建议都可以点 × 或「稍后再说」关掉
- 番茄钟绑定任务：展开任务详情点「专注这一项」，这一轮倒计时就绑在这条任务上（今日条上出现「本轮专注：xxx」的胶囊，点 × 可解绑；跑完一轮自动给这条任务记 1 轮，然后继续绑着它跑下一轮）。被绑过的任务行上会挂一个黄色「N 轮」标记，悬停显示「在这项上专注了 N 轮，约 M 分钟」；详情里也有一行「已累计 N 轮，约 M 分钟」。「数据统计」卡片底部新增「番茄钟投入」，按轮数从多到少列出最费时的几项（最多 6 条），下面汇总「一共 N 轮、约 X 小时」。绑定只存在当前页面里：切换清单、这条任务被勾完成或删掉，绑定就自动松开；计时中途换绑下一条，倒计时不会重置；提前结束的计时不计入
- 按优先级筛选：日期、分类之外新增一行「按优先级筛选」（全部 / 高 / 中 / 低，带计数），与日期、分类、搜索叠加生效，选择会被记住
- 逾期一键顺延：逾期任务的行上多了个闹钟按钮「推到今天」，一点把到期日改成今天；展开详情里还有「顺延 1 天」（没填日期的会设为明天）；批量模式下选中多项可一起「顺延 1 天」。这些操作都支持 6 秒撤销
- 批量整理：点「批量管理」进入多选模式，勾选后可一键完成 / 放回 / 顺延 / 删除 / 统一设分类，「全选」作用于当前能看到的任务（「已完成任务历史」折叠起来时不会选到里面的项）；「放回」把选中的已完成任务退回未完成，「彻底删除」只清掉选中的已完成任务、不进回收站（这两颗按钮只在选中项里有已完成任务时可点）
- 键盘快捷键：`/` 跳搜索、`N` 跳新建、`↑↓` 或 `J K` 选任务、`空格` 完成 / 放回、`Enter` 编辑、`P` 置顶 / 取消置顶、`Delete` 删除（进回收站）、`Esc` 取消；批量面板里 `Ctrl+Enter` 一次添加、`Esc` 收起；页面底部「键盘快捷键」可查看速查表
- 打印清单：页面底部「🖨 打印清单」先给出「打印选项」小面板，可勾选「只打未完成」和「只打今天」（两个选择都会被记住，之后直接 Ctrl+P 也照这个来），再点「开始打印」调起系统打印。打印时自动只输出清单本身——输入框、筛选、按钮、统计等界面元素都会隐藏，每行带上勾选框，可以直接打印出来当纸质清单用
- 深色模式：标题右上角的圆形按钮三态切换「跟随系统 → 浅色 → 深色」，跟随系统时按系统的深浅偏好自动变化；选择会被记住，下次打开在渲染前就定好主题，不会闪白
- 换背景：深色模式按钮旁边多了一个图片按钮，点开是背景面板。上半部分是 8 套预设配色——青绿 / 雾蓝 / 晨橙 / 抹茶 / 紫雾 / 玫瑰 / 米砂 / 石墨，每套都配了浅色与深色两个版本，跟着主题走；下半部分「上传图片」可以拿自己的一张图当背景，图片只在本地处理：先缩到最长边 1600px、再压成 webp 存进浏览器，不上传到任何服务器，实在放不下会提示换一张，「清除图片」即回到预设配色。图上会盖一层半透明遮罩，所以不管换成哪张图，文字都还读得清。配色与图片的选择都会被记住
- 响应式：手机上输入框与按钮竖排，所有可点区域不小于 44px

## 数据存储

全部数据保存在浏览器本机，不上传到任何服务器。`localStorage` 里：`todo.lists` 存清单名册（`{ v: 1, active, lists: [{ id, name }] }`），任务按清单分键存放——默认清单沿用老的 `todo.tasks`，其余清单是 `todo.tasks.<清单 id>`，所以老数据不需要迁移就会出现在「我的清单」里；`todo.prefs` 存偏好（筛选条件、是否隐藏已完成、今日专注开关、统计卡片折叠、主题、背景配色、番茄钟时长、打印选项等），`todo.bgimg` 单独存自选的背景图（那串 base64 有几百 KB，分开存就不会在每次保存偏好时重写它），`todo.trash` 存回收站，`todo.pomo` 存今天的番茄钟轮数与休息次数（`{ day, n, br }`，换一天就重新计），`todo.reminded` 存已经弹过的精确提醒（`{ 任务id: 那次提醒的时刻 }`，只用来防止同一次提醒重复骚扰，清掉也不影响任务本身），`todo.seed` 只记录内置首批清单是否已导入过。任务的 `att` 字段只存附件的元数据（id / 文件名 / 类型 / 大小 / 时间），**文件本体存在 IndexedDB 的 `todo-files` 库、`files` 仓库里**（以附件 id 为键）——`localStorage` 装不下二进制，而且每次保存任务都重写一遍 base64 会很慢。删附件、删任务、清空回收站之后，没人引用的文件会在页面空闲时自动回收。注意 `localStorage` 和 IndexedDB 都按「协议+域名」隔离，本地双击打开与在线地址是两份互不相通的数据。换浏览器、换设备或清除浏览器数据都会导致任务与附件丢失；此页面没有账号与同步功能。需要长期保存或跨设备迁移时，用页面底部的「⬇ 导出备份」。

备份文件是标准 JSON（`{ app, version: 2, exportedAt, lists, trash, files? }`，缩进两格）。`lists` 是清单数组，每项 `{ id, name, tasks }`；`tasks` 里每条除了文字、优先级、到期日、分类、重复之外还带 `note`（备注）、`subs`（子任务数组，每项有 `text` 与 `done`）、`pin`（是否置顶）、`att`（附件元数据）、`focus`（在这项上跑满过几轮番茄钟）和 `remind`（精确提醒的时刻，毫秒时间戳，`0` 或没有这个字段就是不设提醒）。`files` 只在真有附件要打包时出现，形如 `{ "<附件 id>": { name, type, data } }`，`data` 是 base64 的 data URL；单个超过 2 MB 的附件、或打包后整体超过约 12 MB 时会留下不打包并在导出后提示「N 个大附件没打包」，这类附件只留在原机上。`version: 1` 的老备份（只有一包 `tasks`）甚至只有一份任务数组的更老文件都能直接导入，会被并进默认清单；缺 `note`/`subs`/`pin`/`att`/`focus`/`remind` 字段会补成默认值。导入时会校验字段形状，日期对不上下文的脏数据（如 `2026-13-45`）会被清成「无到期日」而不是顺延到别的日子，`focus`/`remind` 里的负数和非数字会被清成 0（`focus` 最多记到 999 轮），回收站里超过 30 天的条目导入时直接丢弃。

## 技术

纯 HTML + CSS + JavaScript，单文件，零依赖（无框架、无 CDN、无构建步骤）。图标为内联 SVG。附件的二进制内容用浏览器自带的 IndexedDB 存，因此「零依赖」仍然成立——没有任何外部脚本或字体。

配色集中在文件顶部 `:root` 的 CSS 变量里：色阶为主色青绿（`--teal-*`），语义色为玫红（高优先级 / 危险操作 / 逾期）、琥珀（中优先级）、深绿（低优先级 / 已完成），背景是浅青渐变。样式不直接写死色号，而是用一层语义变量（`--surface`、`--card-border`、`--page-bg`、`--on-accent`、`--shadow-*`、`--scrim` 等）引用色阶；`[data-theme="dark"]` 里把这一整套变量重定义一遍，深色模式即整体反转，不必逐条改规则。同时设了 `color-scheme`，浏览器滚动条与表单控件会跟着换。想换整套配色，只改 `:root` 与 `[data-theme="dark"]` 这两段即可。热力图用的四档色（`--hm0`–`--hm3`）也放在这两段里，浅色主题越深表示完成得越多、深色主题越亮表示完成得越多，空格子另有一圈 `--hm-line` 描边保证格子形状看得见。

页面背景是 `--page-bg`，它指向成对的 `--bgl`（浅色版）与 `--bgd`（深色版），预设配色只是用 `[data-bg="mist"]` 这类选择器把这一对变量整体换掉，所以新增一套预设只要写两条渐变。自选图片走另一条路：`html[data-bgimg="1"] body::before` 一层 `position: fixed` 的图，上面叠一层 `--bg-wash`（浅色主题 80% 白、深色主题 80% 近黑），最暗的图配浅色、最亮的图配深色这两种极端情况都仍满足下面的对比度要求。

两套主题、八套预设、以及压在最暗 / 最亮图片上的情况都按 WCAG AA 校验过：文字对比度不低于 4.5:1，图标与非文字控件不低于 3:1。
